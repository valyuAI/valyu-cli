# valyu deepresearch

Async deep research with AI-synthesized reports. Spawns a background task and returns a task ID.

## Subcommands

| Subcommand | Description |
|-----------|-------------|
| `create <query>` | Start a new research task |
| `list` | List all research tasks |
| `status <id>` | Check task status |
| `watch [id]` | Poll until complete (omit ID for latest) |
| `cancel <id>` | Cancel a running task |
| `update <id> <instruction>` | Add follow-up instruction |
| `delete <id>` | Delete a task |
| `share <id>` | Toggle public access |

## create

```
valyu deepresearch create <query> [options]
```

### Options

| Flag | Default | Description |
|------|---------|-------------|
| `-m, --mode <mode>` | `standard` | Research depth: `fast`, `standard`, `heavy`, `max` |
| `--no-pdf` | - | Skip PDF generation (PDF on by default) |
| `-w, --watch` | - | Wait for completion inline |

### Mode comparison

| Mode | Time | Use case |
|------|------|---------|
| `fast` | ~5 min | Quick lookups, simple factual questions |
| `standard` | ~10-20 min | Balanced - most use cases (default) |
| `heavy` | ~60 min | Deep analysis, comprehensive reports |
| `max` | ~90 min | Maximum depth and quality |

## status / watch

```
valyu deepresearch status <id>
valyu deepresearch watch [id]
```

### Output (JSON) - completed

```json
{
  "deepresearch_id": "f992a8ab-4c91-4322-905f-190107bd5a5b",
  "status": "completed",
  "query": "AI infrastructure landscape",
  "output": "# AI Infrastructure...\n\n## Overview...",
  "pdf_url": "https://storage.valyu.ai/reports/...",
  "sources": [
    { "title": "Source Title", "url": "https://...", "snippet": "..." }
  ],
  "progress": { "current_step": 5, "total_steps": 5 },
  "cost": 0.50,
  "completed_at": "2024-06-15T10:35:00.000Z"
}
```

### Status lifecycle

```
queued → running → completed | failed | cancelled
                → awaiting_input (HITL checkpoint) → running
```

## Examples

```bash
# Quick research
valyu deepresearch create "Current state of nuclear fusion commercialization" --mode fast -q

# Balanced research with watch
valyu deepresearch create "Competitive landscape: AI search APIs 2025" --watch

# Deep analysis
valyu deepresearch create "Global semiconductor supply chain risks" --mode heavy -q

# List all tasks
valyu deepresearch list

# Check status
valyu deepresearch status f992a8ab-4c91-4322-905f-190107bd5a5b -q

# Watch latest running task
valyu deepresearch watch -q

# Add follow-up instruction
valyu deepresearch update f992a8ab "Also cover regulatory risks"

# Share publicly
valyu deepresearch share f992a8ab
```

## Agent Tips

- **Don't poll manually** - use `deepresearch watch` or `--watch` flag
- Save the `deepresearch_id` immediately - use it to check status later
- `output` field is markdown - render for users or process programmatically
- `heavy` and `max` modes are expensive - use for genuinely complex research only
- Research tasks persist server-side; you can check status hours later
- PDF is generated by default; use `--no-pdf` to skip
- `watch` with no ID automatically watches the latest running task
